# 인계함 서버 설치·운영 안내

관리일지의 **인계 공유(📨 인계함)** 를 쓰려면 사감실 전용 구글 계정에 시트 하나와 이 폴더의 Apps Script를 붙여 웹 앱으로 배포합니다.
운영자 한 사람이 처음 한 번 설치하고, 사감마다 개인 코드를 나눠 줍니다.

> 이 저장소는 공개입니다. 시트 주소, 웹 앱 주소, 개인 코드는 **이 저장소·단톡방·메일 어디에도 적지 마세요.**

## 1. 처음 설치(운영자, 약 20분)

1. **사감실 전용 계정**으로 구글 드라이브에서 새 스프레드시트를 만듭니다(이름은 자유). 이 계정은 2단계 인증을 켜 두세요.
   시트는 다른 사람과 공유하지 않습니다. 사감들은 시트가 아니라 관리일지 앱으로만 봅니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 편집기 왼쪽 **⚙️ 프로젝트 설정**에서 "편집기에서 'appsscript.json' 매니페스트 파일 표시"를 켭니다.
4. `Code.gs`의 내용을 모두 지우고 이 폴더의 `handover-server.gs` 내용을 붙여 넣습니다. `appsscript.json`도 이 폴더의 것으로 바꿔 붙여 넣고 저장합니다.
5. 위쪽 함수 목록에서 `setupSheets`를 골라 **실행**합니다. 처음에는 권한 확인 창이 뜹니다. 운영자가 직접 계정을 골라 허용합니다
   ("확인되지 않은 앱" 경고가 나오면 **고급 → 이동**. 운영자 자신이 붙여 넣은 스크립트이기 때문입니다).
   시트에 `사감`·`인계`·`확인` 탭이 생기면 끝입니다.
6. **사감 탭**의 2번째 줄부터 사감마다 한 줄씩 **이름**만 적습니다(같은 이름이 둘이면 "김사감(태하)"처럼 구분).
   사감 ID·코드·상태·만든 시각 칸은 비워 둡니다.
7. 함수 `issueCodes`를 실행합니다. 빈 칸이 채워집니다. 사감 ID는 `S01`부터, 코드는 `XXXX-XXXX-XXXX` 모양 12자, 상태는 `사용`입니다.
8. **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나(사감실 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   배포하면 나오는 **웹 앱 주소**(`https://script.google.com/macros/s/…/exec` 모양)를 복사해 둡니다.
9. 함수 `installCleanupTrigger`를 한 번 실행합니다. 매일 새벽 3시에 1년 지난 기록을 지우는 정리가 걸립니다.

"모든 사용자"로 두어도 시트 내용은 열리지 않습니다. 웹 앱은 올바른 개인 코드를 가진 요청에만 답하고, 시트 자체는 운영자 계정만 봅니다.

## 2. 태블릿 설정(사감마다, 2분)

1. 운영자가 **웹 앱 주소**와 **그 사감의 개인 코드**를 직접(종이·대면·1:1 메시지) 전합니다. 단톡방에는 올리지 않습니다.
2. 관리일지 **⚙️ 설정 → 📨 인계 공유**에서 웹 앱 주소, 개인 코드, 근무지(선택)를 적고 **설정 저장**을 누릅니다.
   코드의 줄표(-)는 빼도 됩니다. 영문 I·O, 숫자 0·1은 코드에 없습니다.
3. **연결 시험**을 눌러 "○○ 님으로 연결됨"이 나오면 **인계 공유 켜기**를 켭니다.
4. 이후에는 일지를 쓸 때 **📨 다른 사감과 공유**에 체크하면 인계함에 올라갑니다. 받은 인계는 위쪽 **📨 인계함**에서 **확인**·**조치 완료**를 누릅니다.

태블릿 한 대를 두 사람이 같이 쓰면 공유한 인계의 작성자는 그 태블릿에 저장된 코드의 주인이 됩니다. 사감마다 각자 태블릿에서 쓰세요.

## 3. 운영

| 상황 | 할 일 |
|---|---|
| 새 사감이 왔을 때 | 사감 탭 빈 줄에 이름을 적고 `issueCodes` 실행 → 새 코드를 전함(다른 사람 코드는 바뀌지 않음) |
| 사감이 떠났을 때·태블릿 분실 | 그 줄 **상태**를 `중지`로 바꿈(줄을 지우지 마세요 — 지난 인계의 작성자 기록이 남아야 함). 바로 막힙니다 |
| 코드가 남에게 알려졌을 때 | 그 줄 **코드** 칸만 비우고 `issueCodes` 실행 → 새 코드를 그 사감에게 전하고, 그 사감은 태블릿 설정에서 코드를 새로 적음 |
| 정리가 멈췄을 때 | 하루에 지울 줄이 전체의 10%를 넘으면(줄 수와 상관없이) 정리가 스스로 멈추고 계정으로 오류 메일이 옵니다. 시트를 확인한 뒤 `cleanupOldConfirm`을 한 번 실행 |
| 스크립트를 고쳤을 때 | 붙여 넣고 저장한 뒤 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**. 주소가 그대로라 태블릿은 손대지 않아도 됩니다 |

**새 배포**를 또 만들면 주소가 바뀌어 모든 태블릿에서 주소를 다시 적어야 합니다. 고칠 때는 꼭 "배포 관리"에서 새 버전으로 올리세요.

상태 칸은 목록에서 `사용`·`중지` 두 가지만 고를 수 있습니다. 같은 코드가 두 줄에 있으면 두 사람 모두 막히니 코드는 손으로 고치지 말고 위 방법으로만 바꾸세요.

## 4. 정해진 한계

- 인계 한 건은 **2000자**까지, 근무지는 30자, 조치 메모는 200자까지입니다.
- 인계함에는 **최근 14일**(내일 날짜까지) 인계가 최신순으로 최대 200건 보입니다. 시트에는 **1년** 동안 남고, 그 뒤 새벽 정리가 지웁니다.
- 공유한 인계는 사감 모두와 운영자(시트)가 봅니다. 학생 이름은 꼭 필요할 때만 쓰세요.
- 공유 취소는 작성자만 할 수 있습니다. 인터넷이 끊겨 있으면 태블릿에 모아 두었다가 연결되면 보냅니다.
- 관리일지는 **탭(창) 하나로만** 여세요. 같은 태블릿에서 탭 두 개로 동시에 인계를 쓰면 아직 보내지 못한 인계 하나가 덮여 사라질 수 있습니다.
- 관리일지 백업·드라이브 백업에는 인계 공유 설정과 개인 코드가 들어가지 않습니다. 태블릿을 바꾸면 2장을 다시 합니다.
